# Destiny – Travel Booking Website ✈️🌍

Destiny is a modern, full-stack travel booking website that allows users to explore destinations, book trips, and manage their travel plans through a fast, responsive, and user-friendly interface.

---

## 📋 Features

### 👤 User Side
- Browse travel destinations with detailed information
- Search and filter destinations based on location and price
- Book travel packages easily
- Responsive design for desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used
- Frontend: React
- Styling: Tailwind CSS
- Backend: Node.js
- Database: MySQL
- Programming Language: JavaScript (ES6+)

---

## 🚀 Getting Started
